# Helicon Solutions Homebrew Tap

Homebrew casks for Helicon Solutions Mac apps.

## Transcribe

A free, local, Mac-native app that transcribes audio and video to text on-device
with Whisper. No cloud, no upload, no account.

```sh
brew install --cask J3012B/tap/transcribe
```

Or tap first, then install:

```sh
brew tap J3012B/tap
brew install --cask transcribe
```
